[ROBOTS READING VOGUE]

  • A collection of data from the covers of Vogue for each given year, genereating a mean RGB value for each pixel, on every cover.
  • This data is collated from all covers, for each decade. The result is a visualisation of continuation and trends present throughout the years.

    • this is an interesting representation of data, trending styles and art. it provides insight into our patterns as humans and artists - which is a concept i really enjoy.

[BECKETT BRIDGE HARP]

  • Lightscape created visuals which animated each string of the harp in time with the playing of strings on a physical harp located on the Quayside and played by Aisling Ennis.
  • Guests could also pluck the strings on an app, and the corresponding string on the bridge would in turn light up in real-time and play a note on speakers located locally.

    • this project is a perfect example of the combination of physical computing, sound and interactivity; the use of light and sound, in conjunction with a user interface, to alter the external environment.

[CREATE DIGITAL MUSIC]

  • TidalCycles is a free, open source tool that Alex McLean created, with its original inspiration found within research into analysing Indian tabla rhythms.
  • There is a the mini-language inside Tidal for describing polyrhythmic sequences, as well as a unique conception of cyclic time.

    • this is the edge between music theory and interface design, code and musical material, artist and organizer, musician and developer. its insane.

[ART VIA POLARGRAPH]

  • Created using an Arduino micro controller, Victor Leung created an exhibit where his programmed polargraph machine created an artpiece in real time.
  • This creation is categorised as 'drawing art', and there are many different forms of code and robotics which can create a plethora of works.

    • this is a new concept of art that is only just emerging onto the scenescape of contemporary art. its new and interesting; there are so many capabilities with programs such as this one.

[FREEING THE WONDERLIGHT]

  • Pipilotti Rist explores how digital art can engage the whole body, which relates to physical computing through sensors and responsive environments that react to movement or touch.
  • She embraces imperfection and organic forms, encouraging coders to design with randomness, analog inputs, or unpredictable behaviors to create more human-like systems.

    • rist’s work made me think about how code and sensors can shape physical spaces in subtle, organic, and responsive ways - and how even physical computing design can be human-like.
